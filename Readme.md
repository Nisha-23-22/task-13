# Task 13: JavaScript - Check if a Number is Even or Odd

A JavaScript program that checks whether a number is even or odd using an `if-else` statement and shows the result with `console.log()`.

## Files

- `index.html` - simple page that links the CSS and the JavaScript file
- `style.css` - basic styling for the page
- `script.js` - the even / odd program
- `Readme.md` - this file

## How it works

- Four different variables are used: `num1 = 5`, `num2 = 10`, `num3 = 7`, `num4 = 12`.
- For each variable an `if-else` statement checks `number % 2 === 0`.
  - Remainder 0 means the number is **even**.
  - Otherwise the number is **odd**.
- The result is printed with `console.log()`.

## Output (in the browser console)

```
The number 5 is odd.
The number 10 is even.
The number 7 is odd.
The number 12 is even.
```

## How to run

Open `index.html` in a browser, press F12 and open the **Console** tab to see the output. To test other numbers, change the values of the variables at the top of `script.js`.
